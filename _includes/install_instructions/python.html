Python

We will use Python to write and run code, and JupyterLab as our workspace. JupyterLab opens in a web browser but runs on your computer.

We recommend Miniforge for installation. Miniforge includes Python. You do not need to download Python separately. It also includes conda, a tool for installing software and keeping project software in separate environments. In the steps below, you will create a workshop environment called carpentries. This step installs JupyterLab and the Python packages used in the lesson.

Complete setup before the workshop if you can. If a step fails, stop there and contact the workshop organizers. Save the error message or take a screenshot so we can help. If your computer requires IT approval to install software, request that approval before the workshop.

Before you begin

  • Use an internet connection for the downloads and installation.
  • If you already use Anaconda, Miniconda, or Miniforge, ask the organizers whether you can use your existing installation before installing another copy.
  • Choose your operating system below and follow its steps in order. Use the Windows instructions unless you already work in Windows Subsystem for Linux (WSL).
  • We will use a folder called lc-python inside your home folder. This is a different location from the Desktop folder mentioned in the lesson's general setup page.

A terminal is a window where you type commands. On Windows, use Miniforge Prompt; on macOS or Linux, use Terminal. Copy one command line at a time and press Enter (or Return on a Mac). Wait until the prompt returns before entering the next command. The prompt is the text or symbol beside the cursor when the terminal is ready for another command. Do not copy prompt symbols such as $ or >.

Windows

1. Install Miniforge
  1. Visit the Miniforge download page and choose Windows x86_64. These steps are for a Windows PC with an Intel or AMD processor. If your PC uses an ARM processor, contact the organizers for help choosing an installation route.
  2. Open the downloaded .exe file. Read and accept the license, choose Just Me, and keep the default installation folder.
  3. Keep Create start menu shortcuts selected. Leave Add Miniforge3 to my PATH environment variable unchecked. You will use Miniforge Prompt, so adding Miniforge to PATH is not needed.
  4. Finish the installation. Open the Windows Start menu, search for Miniforge Prompt, and open it.
  5. Check that conda is available:
conda --version

You should see conda followed by a version number. Your number may differ from examples you see elsewhere.

2. Prepare your workshop files
  1. In File Explorer, click the address bar, type %USERPROFILE%, and press Enter. This opens your home folder.
  2. Create a folder there called lc-python. If it already exists, use that folder.
  3. Right-click carpentries_environment.yml and choose Save link as (the wording varies by browser). Save it inside lc-python. If the save dialog offers a file type, choose All files. Keep the filename exactly carpentries_environment.yml, with no extra .txt extension.
  4. Download the lesson data ZIP file and save it inside lc-python.
  5. Right-click data.zip and choose Extract All. Set the destination to your lc-python folder. After extraction, that folder should contain a data folder with CSV files inside it. If extraction creates an extra enclosing folder, move the folder containing the CSV files into lc-python and name it data.

Your lc-python folder should now contain carpentries_environment.yml and a data folder. It may also contain data.zip, which you can keep.

3. Create the workshop environment

Return to Miniforge Prompt. Run these commands one line at a time:

cd /d "%USERPROFILE%\lc-python"
conda env create -f carpentries_environment.yml

This downloads and installs the workshop software. It may take several minutes and display many lines of text. Wait for the prompt to return. If you see an error, stop and use the troubleshooting section below.

4. Open JupyterLab
conda activate carpentries
jupyter lab

JupyterLab should open in your browser. Keep Miniforge Prompt open while you use it. Continue to Check that setup works below the tabs.

5. Open it again on workshop day

Open Miniforge Prompt and run:

cd /d "%USERPROFILE%\lc-python"
conda activate carpentries
jupyter lab

You only need to create the environment once.

macOS

1. Install Miniforge
  1. Open the Apple menu → About This Mac. If you see an Apple M-series chip, choose arm64 (Apple Silicon) on the Miniforge download page. If you see an Intel processor, choose x86_64 (Intel).
  2. Save the installer in your Downloads folder. These instructions use the file ending in .sh, which you run in Terminal. If you downloaded a .pkg instead, use that installer's instructions or ask the organizers for help.
  3. Open Terminal: press Command+Space, type Terminal, and press Return.
  4. Run one of the commands below, matching the installer you downloaded.

Apple Silicon:

bash ~/Downloads/Miniforge3-MacOSX-arm64.sh

Intel:

bash ~/Downloads/Miniforge3-MacOSX-x86_64.sh

Follow the installer prompts:

  • Press Return to begin. Read the license, using Space to advance through it. Type yes and press Return to accept.
  • Press Return to accept the default installation location, ~/miniforge3. The ~ symbol means your home folder.
  • Type yes when asked whether to initialize conda. This sets up your terminal to find conda.
  • When installation finishes, close the Terminal window and open a new one.

Check that conda is available:

conda --version

You should see conda followed by a version number.

2. Prepare your workshop files

  3. Download the lesson data ZIP file and save it inside lc-python.
  4. Double-click data.zip to extract it. If your browser already extracted it in Downloads, move the resulting data folder into lc-python. Check that data contains CSV files.

Your lc-python folder should now contain carpentries_environment.yml and a data folder. It may also contain data.zip, which you can keep.

Windows Subsystem for Linux (WSL)

Use these steps only if WSL is already installed and you normally work in it. You do not need to install WSL for this workshop. Otherwise, use the Windows tab.

1. Install Miniforge inside WSL
  1. Open your WSL Linux terminal, such as Ubuntu, from the Windows Start menu. These commands belong in that Linux terminal.
  2. Run the commands below one line at a time. They download the Linux installer into your Linux home folder and then run it. If curl is not available, stop and contact the organizers.
curl -fL "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-$(uname -m).sh" -o "$HOME/Miniforge3-WSL.sh"
bash ~/Miniforge3-WSL.sh

Follow the installer prompts:

  • Press Enter to begin. Read the license, using Space to advance through it. Type yes and press Enter to accept.
  • Press Enter to accept the default installation location, ~/miniforge3. The ~ symbol means your Linux home folder.
  • Type yes when asked whether to initialize conda.
  • When installation finishes, close the WSL terminal window and open a new one.

Check that conda is available:

conda --version

You should see conda followed by a version number.

2. Prepare your workshop files

Run these commands one line at a time in WSL. They create your workshop folder and download the files directly into it, so you do not need to move files from Windows Downloads.

mkdir -p ~/lc-python
cd ~/lc-python
curl -fL "https://raw.githubusercontent.com/carpentries/workshop-template/refs/heads/gh-pages/data/carpentries_environment.yml" -o carpentries_environment.yml
curl -fL "https://librarycarpentry.github.io/lc-python-intro/files/data.zip" -o data.zip
python -m zipfile -e data.zip .

The final command extracts the ZIP file into the current folder. Check the contents:

ls
ls data

The first command should list carpentries_environment.yml and data, along with data.zip. The second should list CSV files. If your folders differ, contact the organizers.

3. Create the workshop environment
conda env create -f carpentries_environment.yml

This downloads and installs the workshop software. It may take several minutes and display many lines of text. Wait for the prompt to return. If you see an error, stop and use the troubleshooting section below.

4. Open JupyterLab
conda activate carpentries
jupyter lab --no-browser

Keep the WSL terminal open. Copy the complete address beginning with http://localhost: from the terminal into your Windows browser, including the part containing token=. This token grants access to your JupyterLab session; do not share it. Continue to Check that setup works below the tabs.

5. Open it again on workshop day

Open your WSL terminal and run:

cd ~/lc-python
conda activate carpentries
jupyter lab --no-browser

Use the new browser address printed in the terminal. You only need to create the environment once.

  2. Choose File → New Launcher. Under Notebook, click Python 3 (the label may also include ipykernel).
  3. Click the first empty cell in the notebook and type the code below. Press Shift+Enter to run it.

Save any notebook work with Ctrl+S (Windows or Linux) or Command+S (Mac). To stop JupyterLab, return to the terminal window where you started it and press Ctrl+C. If asked to shut down the server, type y and press Enter. You can then close the browser tab and terminal.

Troubleshooting

Windows blocks the installer

Check that you downloaded the installer from the official Miniforge download page linked above. Some downloaded files have an Unblock checkbox under right-click → Properties → General. If that option is present and your organization's rules permit it, select it and try again. This does not resolve every type of security block. If Windows says your organization or administrator has blocked the app, contact IT or the organizers for help.

The installer file cannot be found

Check where your browser saved the installer and whether its name matches the command. The macOS and Linux commands assume it is in your home folder's Downloads folder with its original filename. If your browser added a suffix such as (1), the name will differ. Ask the organizers for help rather than repeatedly downloading the installer.

Windows says conda is not recognized

Open Miniforge Prompt from the Start menu and try conda --version there. The workshop commands are written for Miniforge Prompt.

macOS, Linux, or WSL says conda: command not found

First close the terminal window and open a new one. If the error continues and you accepted the default installation location, run the command for your shell below.

macOS using the default zsh shell:

~/miniforge3/bin/conda init zsh

Linux or WSL using bash:

~/miniforge3/bin/conda init bash

Then close the terminal window, open a new one, and try conda --version again. If you chose another installation folder, use another shell, or still see an error, contact the organizers.

The environment file cannot be found or read

Make sure you ran the cd command for your operating system and saved carpentries_environment.yml inside lc-python. Check for an extra extension such as .txt. If the download link shows 404 Not Found, tell the organizers: the link needs checking. If you open the saved YAML file in a text editor, its first line should be name: carpentries, rather than a web page or error message.

Environment creation is slow or fails

Solving the environment and downloading packages can take several minutes. Wait for the prompt to return. If you receive an error, save the message and contact the organizers. If the message says an environment named carpentries already exists, ask us to check it before removing or replacing it.

conda activate carpentries fails, or jupyter lab is not found

Check which environments are available:

conda env list

If carpentries is listed, try conda activate carpentries again. After activation, an asterisk in the conda env list output should mark it as the active environment. If activation fails, the environment is missing, or JupyterLab still will not start, share the error with the organizers. Do not delete an existing environment to troubleshoot on your own.

JupyterLab does not open in a browser

Keep the terminal open. If it shows a web address beginning with http://localhost: or http://127.0.0.1:, copy the full address into your browser, including any token= portion. Do not share the token. If the browser still cannot connect, or the terminal shows an error instead of an address, contact the organizers.

JupyterLab opens, but the data folder is missing

You may have started JupyterLab from another folder. Stop it using the instructions above. Then follow Open it again on workshop day in your operating system's tab, including the cd command. If the folder is still missing, check that you extracted data.zip into lc-python.
