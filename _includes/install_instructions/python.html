Python

Python is a popular language for research computing. We will use Python through JupyterLab, which runs in a web browser.

To make setup easier, we recommend installing Python using Miniforge. This will also install JupyterLab and the packages we need for the workshop.

Please complete the steps below before the workshop. If you get stuck, stop and we will help you during the session.

Before you begin

Create a folder on your Desktop called lc-python. This will be your working folder for the lesson. 

Desktop/

Windows note: Windows Defender blocking the installer
Windows may block the Miniforge installer with an "unrecognized app" warning and no option to run it anyway.

To fix this:

  1. Right-click the downloaded .exe file and select Properties.
  2. On the General tab, look for an Unblock checkbox at the bottom.
  3. Check Unblock, click OK, then run the installer again.

This is a common issue on managed Windows devices (including Windows 11 Education).

Windows note: OneDrive users
If your Desktop or Documents folders are synced with OneDrive, you may run into issues creating the Python environment.
  • We recommend working in your Desktop folder for this workshop.
  • If you see errors during setup, OneDrive may be the cause.
  • If possible, make sure your Desktop is available locally on your machine.

If setup fails and you're not sure why, stop and we will help you during the workshop.

  1. Download and install Miniforge from conda-forge.org/download.
  2. During installation, make sure to check Add Miniforge3 to my PATH environment variable.

Mac note: Which version to download?

Miniforge comes in two versions for Mac:

  • arm64 (Apple Silicon) — for Macs with an M1, M2, M3, or M4 chip (most Macs from late 2020 onward)
  • x86_64 (Intel) — for older Intel Macs

To check: click the Apple menu () → About This Mac. If you see "Apple M1" (or M2, M3, M4), choose arm64. If you see "Intel Core i…", choose x86_64.

  1. Download the Miniforge installer for your Mac from conda-forge.org/download. You will get a file ending in .sh — this is a shell script, not a regular installer. Do not try to open it by double-clicking.
  2. Create a folder on your Desktop called lc-python.
  3. Download the carpentries_environment.yml and save it in ~/Desktop/lc-python.
  4. Open Terminal. You can find it in Applications → Utilities, or press Command+Space and type Terminal.
  5. Run the installer by typing the command below and pressing Enter:
bash ~/Downloads/Miniforge3*.sh

Follow the prompts:

  • Press Enter or Space to scroll through the license, then type yes and press Enter to accept it.
  • Press Enter to accept the default install location (~/miniforge3).
  • Type yes when asked whether to initialize Miniforge3 — this lets your terminal find conda automatically.
  1. Close Terminal completely and open a new window. This is required — conda will not work in the same window where you ran the installer.
  2. Verify the install worked:
conda --version

You should see something like conda 24.x.x. If you see command not found, see troubleshooting below.

  1. Create the workshop environment:
cd ~/Desktop/lc-python
conda env create -f carpentries_environment.yml
  1. Download the data zip file and unzip it inside lc-python.
  2. Test setup:
conda activate carpentries
jupyter lab

You should see the data folder in JupyterLab.

WSL note: your Downloads folder is in a different place

If you are using Windows Subsystem for Linux (WSL), files you download in your Windows browser are not in ~/Downloads inside WSL. They are in your Windows user folder, accessible from WSL at: 

/mnt/c/Users/<your-windows-username>/Downloads/

Replace <your-windows-username> with your actual Windows username when running the installer command in step 5 below. We also recommend working from your Linux home directory (~/lc-python) rather than ~/Desktop, since the Desktop path in WSL varies by setup.

  1. Download the Miniforge installer for Linux from conda-forge.org/download. You will get a file ending in .sh — this is a shell script you will run in step 4.
  2. Create a working folder:
mkdir -p ~/Desktop/lc-python

WSL users: use mkdir -p ~/lc-python instead.

  1. Download the carpentries_environment.yml and save it in your lc-python folder.
  2. Open a terminal and run the installer:
bash ~/Downloads/Miniforge3*.sh

WSL users: replace ~/Downloads/ with /mnt/c/Users/<your-windows-username>/Downloads/.

Follow the prompts:

  • Press Enter or Space to scroll through the license, then type yes and press Enter to accept it.
  • Press Enter to accept the default install location (~/miniforge3).
  • Type yes when asked whether to initialize Miniforge3.
  1. Close your terminal and open a new one. This is required — conda will not work in the same window where you ran the installer.
  2. Verify the install worked:
conda --version

You should see something like conda 24.x.x. If you see command not found, run conda init bash (or conda init zsh if you use zsh), then open a new terminal and try again.

  1. Create the workshop environment:

Troubleshooting

  • Windows: Miniforge installer blocked by Windows Defender — Right-click the .exe file, select Properties, and check the Unblock box at the bottom of the General tab. Click OK, then run the installer. This is common on managed Windows devices (including Windows 11 Education).
  • conda: command not found after installing Miniforge — Close your terminal completely and open a new one. On Mac, if the error persists, run conda init zsh (or conda init bash if you use Bash), then open a new terminal window.
  • Windows: conda not recognized in Command Prompt or PowerShell — Use Miniforge Prompt (installed with Miniforge), not the regular terminal.
  • Environment creation hangs at "Solving environment..." — Run conda config --set channel_priority strict, then try creating the environment again.
  • jupyter lab not found — Make sure you ran conda activate carpentries first. If the problem continues, the environment may not have installed correctly. Remove it with conda env remove -n carpentries and recreate it.
  • Mac (Apple Silicon) — Make sure you downloaded the arm64 Miniforge installer from conda-forge.org/download, not the x86_64 version.

For additional common setup issues, see the Carpentries Configuration Problems and Solutions wiki. Note that some entries there predate Miniforge and may refer to Anaconda — the conda commands are the same.
