<div class="uc-section">
  <div class="uc-section-header"><h2>How We Learn Together</h2></div>
  <div class="uc-two-col">
    <div class="uc-col">
      <h3>Our Pedagogy</h3>
      <ul>
        <li><strong>Live Coding:</strong> We learn by doing together; mistakes are pedagogical opportunities.</li>
        <li><strong>Mental Models:</strong> Building understanding by connecting new skills to your daily work.</li>
        <li><strong>No Overload:</strong> We focus on a few key concepts to ensure mastery over speed.</li>
      </ul>
    </div>
    <div class="uc-col">
      <h3>Managing Expectations</h3>
      <ul>
        <li><strong>Practical Competence:</strong> Skills you can apply immediately in your library role.</li>
        <li><strong>Collaborative Pace:</strong> We move as a group; your questions help set the speed.</li>
        <li><strong>Mistakes are Expected:</strong> Coding is a process of troubleshooting and persistence.</li>
      </ul>
    </div>
  </div>
</div>

  <div class="uc-section-header"><h2>Zoom Tools &amp; Support</h2></div>

  <p class="uc-sub-header">Zoom Etiquette</p>
  <ul class="uc-plain-list">
    <li>🖐 <strong>Raise Hand</strong> for verbal questions</li>
    <li>💬 Use <strong>Chat</strong> for technical issues &amp; help</li>
    <li>✅ Use <strong>Non-verbal icons</strong> (Yes/No/Speed)</li>
  </ul>

  <p class="uc-sub-header">Communication</p>
  <ul class="uc-plain-list">
    <li>Post questions in <strong>Etherpad</strong> shared notes</li>
    <li>Helpers monitor chat for immediate aid</li>
    <li>Typing <strong>"I'm stuck"</strong> is a complete sentence</li>
  </ul>

  <div class="uc-callout">"Questions help everyone. You are not interrupting."</div>
</div>
